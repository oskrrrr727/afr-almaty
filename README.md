# AFR in Almaty — сайт аренды квартир

Лендинг компании **AFR in Almaty**: аренда премиум-квартир в Алматы посуточно и по часовой.
ЖК «Молодёжный», ул. Шевченко 85.

## Что внутри

- Каталог из 10 квартир, у каждой карусель фотографий
- Тарифы (по часовой / день-ночь / сутки) и полная таблица цен
- Оформление праздников
- Правила проживания, FAQ, отзывы, карта
- Три языка: русский, қазақша, English
- Бронирование через WhatsApp — без бэкенда

## Структура

```
index.html          — вся разметка
styles.css          — стили (тёмная тема, адаптив)
script.js           — данные квартир, переводы, карусели, анимации
assets/
  apartments/1..10/ — фото квартир (1.jpg, 2.jpg, …)
  decor/1..3/       — фото оформления праздников
```

## Как изменить контент

Почти всё правится в `script.js`:

- **Квартиры** — массив `apartments` в начале файла: название, площадь, число фото
- **Оформление** — массив `decor`
- **Тексты сайта** — объект `T` (три языка: `ru`, `kk`, `en`)
- **Номер WhatsApp** — константа `WHATSAPP`

Цены в таблице тарифов правятся в `index.html`, секция `#tariffs`.

## Как добавить фото

Положить файлы в папку нужной квартиры с именами по порядку:

```
assets/apartments/1/1.jpg
assets/apartments/1/2.jpg
...
```

Количество фото указывается в поле `photos` соответствующей квартиры в `script.js`.

## Локальный запуск

Открыть `index.html` в браузере — сборка не требуется.
